# Tobs 人格助手（tobs-persona-helper）

把人格提示词改到像人在说话——这是它在 [Tobs](https://github.com/BotHarness/DeepSeekBot)（botharness）里的**人设与工作手册**，不含可执行代码。

## 这是什么

一个 Tobs Bot 的分享导出：一份 29KB 的人格工程师手册（`SOUL.md`）、一份 Core Memory 模板，加上外观配置（头像、横幅、标签、配色）。可以把它当「怎么把一张 AI 味很重的人格卡改成像真人发消息」的方法论读，也可以直接装进自己的 Bot，让它当人格工程师。

## 手册里能直接用的几条

- **三条铁律 + A4 门禁四问**：答不出四问就不动文本；先问用户，再动笔。
- **0.4 答卷模板**：改卡前先输出五段答卷（现状、病灶、判据、改法、验收），不许直接重写。
- **0.8 方向不明时**：考证 → 推演 → 询问；问的是选择题，不是开放题。
- **1.3 抽象要求 → 可观察判据**：把「活泼一点」翻成能验的行为，而不是换一个形容词。
- **B19 温度与密度**：频率类要求只能写正向密度（「十句里七八句带」），写「一两处就够」等于写成禁令；作品里的稀有度搬到单轮对话会失效，得换成「何时收掉」。
- **B20 属性 → 机制**：标签不算设定，「被冷落会不会难受」这类机制才算。
- **B21 输出节奏是设定**：一轮几条、每条多长，本身就是人物的一部分。
- **B13 交付前 checklist + B17 对话模拟自测**：改完立刻能跑、能验、能报不确定项。
- **T2 工具契约 / T5 十八段系统提示**：知道自己在 tobs 里跑，也知道谁在跟自己抢控制权。

## 怎么用

**只读方法论** — 直接看 `SOUL.md` 的 `0.x` 与 `B` 系列，那部分跟具体角色无关，换成任何人物都适用。

**装进自己的 Tobs Bot** — 新建 Bot 时：人设填 `SOUL.md` 正文，Core Memory 填 `MEMORY.md` 的约定部分，头像和横幅用 `.botharness` 里的图；`bot.json` 的 `tags`、`bio`、`primaryColor` 可照抄。

**还原外观** — `banner.png` 对应 `bot.json` 里 `banner.recipe`（`scene: summer`，`seed: 2462237217`），两者一致。
